# Merely Made

Merely Made builds local-first software for navigating knowledge, making
music, and sharing computation among trusted peers.

[Explore the complete repository family and its relationships →](https://mer3ly.net/repos/)

## Platform

- **[Mere](https://github.com/merely-made/mere)** is a graph-first library for
  addressable content, spatial interfaces, local memory, and trusted exchange.
- **[Genet](https://github.com/merely-made/genet)** is an embeddable Rust web
  engine with static, interactive, scripted, and full-web profiles.
- **[Retinue](https://github.com/merely-made/retinue)** is a peer-to-peer and
  radio stack for identity, links, resources, and reliable streams.

## Products

- **[Turnstone](https://github.com/merely-made/turnstone)** is a graph-shaped
  browser for relating, curating, and cooperatively browsing the web.
- **[Woodshed](https://github.com/merely-made/woodshed)** is a practice toolkit
  for musicians.
- **[Hocket](https://github.com/merely-made/hocket)** is a turn-based,
  cooperative, peer-to-peer audio looper.
- **[Isometry](https://github.com/merely-made/isometry)** is a pixel-art
  isometric virtual tabletop with peer-to-peer play.

## Foundations

[Netrender](https://github.com/merely-made/netrender),
[Vano](https://github.com/merely-made/vano),
[Wavicle](https://github.com/merely-made/wavicle), and the focused
[wgpu interop crates](https://mer3ly.net/repos/#repo-wgpu-graft) support the
platform and products above.
